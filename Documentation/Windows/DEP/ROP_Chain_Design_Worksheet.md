# ROP Chain Design Worksheet

**Purpose:** Reusable paper worksheet for designing and debugging ROP chains.

**Use it the same way every time:** define the target machine state first, then
identify the gadgets that transform the current state into that target state.

---

## Process Reminder

```text
1. Goal
2. API / primitive
3. Desired call frame
4. Desired register state
5. Capabilities needed
6. Chain
7. Verify
```

Experienced exploit developers do not start by hunting gadgets. They start by
defining the machine state they need, then search for gadgets that transform
the current state into that target state.
