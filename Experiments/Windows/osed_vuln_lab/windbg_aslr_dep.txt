OSED WinDbg Commands - aslr_dep Profile (VM-Only)
=================================================

Target profile
- aslr_dep: /GS- /DYNAMICBASE /NXCOMPAT

Launch
- windbg -g -G osed_vulnsvc.exe 9999

Setup
- .symfix
- .reload /f
- sxe av

Focus
- Leak-assisted module base discovery + DEP-aware control flow.

Commands
- !analyze -v
- r
- kb
- dd esp L60

Leak workflow
- Trigger OP_LEAK from python/protocol_smoketest.py.
- Record leaked pointer and map to module:
  - lm
  - lmv m osedhelper

ASLR-aware review
- Re-check module bases each launch.
- Record each required gadget RVA once.
- Recompute every absolute gadget, writable-slot, and API-wrapper address as
  leaked module base + verified RVA on each process launch.

VirtualProtect verification
- bp kernel32!VirtualProtect
- g
- r
- dd esp L20
- g

Notes
- Use the same PUSHAD primitive inventory as windbg_dep.txt.
