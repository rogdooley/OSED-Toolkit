# OSED Lab Notebook

Printable Markdown worksheets for exploit development, reverse engineering, and
debugging. Each worksheet is meant to externalize reasoning so the work becomes
repeatable, reviewable, and easier to improve.

## Working Rule

Start with the worksheet that matches the problem. Do not skip directly to
tooling or code until the reasoning is on paper.
